# Contributing to Alpha Quant Academy

Thank you for considering contributing to Alpha Quant Academy! 🎉

We welcome contributions from the community. Here's how you can help:

## 🤝 Ways to Contribute

### 📝 Documentation
- Fix typos or grammatical errors
- Improve explanations in notebooks
- Add more examples
- Translate content to other languages

### 🐛 Bug Reports
- Report issues with code
- Identify broken links
- Point out incorrect calculations

### 💡 Feature Requests
- Suggest new topics
- Propose new projects
- Recommend additional exercises

### 📓 New Content
- Submit new notebook tutorials
- Create additional exercises
- Develop new projects

## 📋 Contribution Process

### 1. Fork the Repository
```bash
git clone https://github.com/mangeshraut712/alpha-quant-academy.git
cd alpha-quant-academy
```

### 2. Create a Branch
```bash
git checkout -b feature/your-feature-name
```

### 3. Make Your Changes
- Follow our code style guidelines
- Add tests if applicable
- Update documentation

### 4. Test Your Changes
```bash
# Install development dependencies
pip install -r requirements.txt

# Run notebooks to verify they work
jupyter nbconvert --execute curriculum/**/*.ipynb
```

### 5. Commit Your Changes
```bash
git add .
git commit -m "Add: description of your changes"
```

### 6. Push and Create PR
```bash
git push origin feature/your-feature-name
```
Then open a Pull Request on GitHub.

## 📐 Style Guidelines

### Code Style
- Follow PEP 8 for Python code
- Use meaningful variable names
- Add comments for complex logic
- Keep functions small and focused

### Notebook Style
- Start with a clear title and learning objectives
- Use markdown cells to explain concepts
- Include practical examples
- Add exercises at the end
- Provide solutions in separate cells

### Commit Messages
Use conventional commits:
- `Add:` for new features
- `Fix:` for bug fixes
- `Update:` for updates to existing content
- `Docs:` for documentation changes
